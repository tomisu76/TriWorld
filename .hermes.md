# TriWorld project instructions for Hermes

Najprv otvor a prečítaj v tomto poradí:

1. `HERMES_START_HERE.md`
2. `HERMES_TRIWORLD_MASTER_PROMPT_2026.md`
3. `docs/hints/HERMES_VERIFICATION_RULES.md`
4. `docs/resources/README.md`
5. existujúci `RESEARCH.md`, ADR, contracts, test matrix a risk register

`docs/hints/HERMES_VERIFICATION_RULES.md` je povinný protokol pre tvrdenia
`PASS`, `COMPLETE`, kompatibilitu so stock obsahom a pripravenosť na runtime.
Nemení architektúru ani poradie fáz z master promptu; určuje iba minimálny
dôkaz potrebný na pravdivé uzavretie gate.

Tento repozitár už môže obsahovať používateľský alebo skorší agentový scaffold. Pred prvou zmenou vykonaj `git status`, inventár súborov a environment report. Nič nemaž, neresetuj, neprepisuj ani neregeneruj plošne bez dôkazu, že je to bezpečné a v rozsahu úlohy.

## Nevyjednateľné pravidlá

- Cieľom nie je iba vytvoriť ZIP; cieľom je deterministický, prenosný, skutočne načítateľný a jazditeľný BeamNG level.
- Každú cestu modeluj oddelene ako topológiu, fyzickú geometriu, vizuálnu vrstvu a AI navigáciu.
- `DecalRoad` nie je fyzická kolízia. SUMO sieť nie je 3D vozovka. Road Architect session nie je runtime level, kým nie je finalizovaná, uložená, znovu načítaná a overená.
- TriWorld kanonický road contract používa `[x, y, z, halfWidth]`; objektová pozícia musí súhlasiť s prvým node. Verejná dokumentácia cieľovej verzie môže štvrtú BeamNG hodnotu nazývať `width`, preto versioned serializer musí jej runtime význam zmerať canary testom a prípadnú konverziu vykonať explicitne — nikdy ticho nezmeň RoadIR jednotku.
- Iba autoritatívna AI cesta má kladnú drivability. Protismerné či pomocné vizuálne vrstvy nesmú vytvárať falošné navigačné hrany.
- Bridge/tunnel crossing nie je križovatka bez skutočnej topologickej konektivity.
- BeamNG Lua/editor API nikdy nehádaj; over symbol v source presne nainštalovanej verzie a potom urob runtime canary.
- Používaj web research, evidence ledger a ohraničených read-only subagentov podľa `docs/resources/`.
- NotebookLM je voliteľný research nástroj. Nie je autorita ani build dependency.
- Italy používaj iba ako benchmark systémových vlastností. Chránené assety nekopíruj ani nedistribuuj.
- Tajomstvá, používateľské cesty, cookies, licenčne chránené assety a súkromné dáta nesmú skončiť v repozitári, logu, prompte ani NotebookLM.
- Každé tvrdenie označ stavom: `implemented`, `statically validated`, `integration tested`, `runtime verified`, `visually inspected` alebo `not yet proven`.
- Nehlás úspech bez dôkazu. Neznižuj gate preto, aby prešiel chybný build.

## Spôsob práce

Najprv research a contracts, potom najmenší offline vertical slice, potom skutočný BeamNG load-and-drive gate. OSM, DEM, SUMO, Blender a scenery pridávaj po vrstvách až po prechode predchádzajúceho gate. Výskum môže byť paralelný; integrácia a editovanie spoločného súboru majú jedného vlastníka.
