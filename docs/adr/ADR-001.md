# ADR 001: MapFrame & Coordinate System

Status: Accepted
Date: 2026-07-29

## Context
BeamNG and GIS data require strict coordinate handling. WGS84 (Lat/Lon) is unsuitable for local 3D processing.

## Decision
All internal processing will use a local Metric MapFrame based on a projected CRS (UTM or Transverse Mercator) to ensure metric correctness for roads, terrain, and collision meshes.

## Consequences
- Requires PROJ integration for all coordinate transforms.
- Must store provenance of original CRS for auditability.
