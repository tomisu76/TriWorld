# ADR 002: Pipeline Separation

Status: Accepted
Date: 2026-07-29

## Context
The generation pipeline mixes geographic processing, civil engineering, and 3D authoring.

## Decision
Separate the pipeline into:
1. Deterministic Compiler (Geometry/Topology/Topology-to-Mesh)
2. Authoring Bake (Road Architect/World Editor)

## Consequences
- Allows automated CI testing of the compiler without requiring a GUI.
- Separates physical truth (RoadIR) from visual representation (Road Architect).
