## Lockfile Strategy
1. `uv.lock` — Python dependencies (committed)
2. `pnpm-lock.yaml` — Node dependencies (committed)
3. `toolchain.lock.json` — External tool versions (committed, no secrets)
4. `.env` — Local paths only (NOT committed, use `.env.example`)

## Update Policy
- Tool versions only updated via explicit decision recorded in ADR
- Lockfiles updated via `uv lock --upgrade` / `pnpm update` with PR
- BeamNG version pinned until migration ADR is written
- SUMO version pinned until netconvert output compatibility is verified
