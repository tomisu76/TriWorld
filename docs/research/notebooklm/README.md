# Reviewed NotebookLM exports

Tento adresár obsahuje iba človekom skontrolované, sanitizované exporty podľa `docs/resources/NOTEBOOKLM_PLAYBOOK.md`.

Každý export musí uvádzať:

- notebook a režim;
- dátum;
- exact prompt;
- selected source IDs;
- checksum source manifestu;
- reviewer;
- overené a neoverené tvrdenia;
- otvorené citations/primárne zdroje;
- potrebné canaries.

Neukladaj sem raw proprietary source, stock BeamNG assety, API keys, cookies, osobné údaje ani automatický výstup bez kontroly.
