# TriWorld

drivable BeamNG.drive maps from real-world data.

## Documentation model

- `docs/CURRENT_HANDOFF.md` changes as work advances.
- `docs/implementation-status.md` tracks capabilities and verification depth.
- `docs/resources/` contains reusable guidance and blank templates.
- `docs/research/` contains project-specific research outputs.
- `docs/adr/` records architectural decisions.
- `docs/operations/` contains gates, risks, state and operational procedures.

[`RESEARCH.md`](RESEARCH.md) is an archived initial planning snapshot, not the
current roadmap. Version-sensitive claims must always be revalidated against the
pinned environment and current evidence ledger.
